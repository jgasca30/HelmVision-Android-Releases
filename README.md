# HelmVision Android Releases

Public release repository for **HelmVision**, an independent Android client for user-selected, self-hosted Frigate NVR servers.

HelmVision is not affiliated with or endorsed by Frigate, Inc. `Frigate` is used only to identify compatible server software and functionality.

## Current release identity

- Product: **HelmVision**
- Android package: `app.helmvision.android`
- Current validated direct-release baseline: **0.7.11 / versionCode 84**
- Private source repository: `jgasca30/HelmVision-Android`

Future HelmVision direct-distribution APK releases will be published here. Release assets use names such as:

`helmvision-0.7.10.apk`

Historical pre-HelmVision releases remain preserved in the legacy release repository and are not part of the active HelmVision repository history.

## Privacy policy

The public HelmVision privacy policy is published from this repository through GitHub Pages at:

`https://jgasca30.github.io/privacy-policy.html`

The legacy `Frigate-Android-Releases` repository remains online for historical compatibility and policy hosting.

## Distribution

This repository contains public HelmVision release artifacts and public policy material only. Application source is maintained separately in the private `HelmVision-Android` repository.

Release signing material, private keys, credentials, and publishing tokens are never stored in this public repository.
